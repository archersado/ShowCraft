# Spec Delta

## Purpose

让不同版本的视频演示从发布说明和实际代码变更共同发现产品入口，避免以自然语言猜测 UI 操作路径。

## ADDED Requirements

### Requirement: 生成特性代码证据包

系统 SHALL 为每个解析出的特性检索受允许 Git 仓库中的关联提交、diff、文件或符号，并输出带来源引用与置信度的证据包。

#### Scenario: 找到感知与 IM 路由入口

- **WHEN** 系统处理 StartUpOS `v0.3.3` 的感知与 IM 路由特性
- **THEN** 输出至少一个可回链到提交或代码位置的入口候选

### Requirement: 保护低置信度候选

系统 MUST NOT 将缺少代码证据或低于配置置信度阈值的候选直接转为自动化操作。

#### Scenario: 证据不足时降级

- **WHEN** 特性只关联到内部实现且无法定位可观察产品入口
- **THEN** 系统将其标为需要人工补充或旁白处理，而不执行产品操作
