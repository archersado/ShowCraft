# 证据与溯源审计

判断现有项目知识或跨项目主题是否值得信任。消费者需要一份能直接安排修正工作的报告，而不是笼统的“文档需完善”。

发现无来源结论、失效路径、证据冲突、把推断写成事实、机制缺少结构或运行映射、以及不足两个项目却被晋升的主题。每个发现包含位置、问题、证据状态、影响和最小修复建议，并区分项目知识问题与原项目本身的问题。旧 `space/time/logic` 文件按 [结构—运行—机制视图](view-model.md) 兼容读取，不仅因名称旧而报告问题。

审计不自动修改原始项目或知识产物。只输出发现和建议；经用户明确要求后，才可修正生成的知识文件。不要读取秘密或被排除的路径。
