# 业务架构：运行

## 主要事件流

1. 运营团队通过 CLI 提交 Changelog 文档地址；默认可传 StartUpOS 的版本发布说明路径，ShowCraft 解析特性事实。
2. ShowCraft 生成视频生产任务、中文旁白、镜头和操作计划；运营团队可检查输入事实。
3. ShowCraft 在本地启动并自动操作 StartUpOS 桌面版，生成录屏、中文 Edge TTS 配音、字幕和渲染清单。
4. 首发以 `v0.3.3` 的四组特性驱动镜头；ShowCraft 以“开场/结尾 10–15 秒 + 每项特性 12–20 秒”组织时长，超过 90 秒拆成系列；CLI 返回 HTTP 预览链接，运营团队据此人工批准或退回。[S-004, S-005]

## 业务状态

`同步 → 已校验 → 本地生产中 → 待人工审核 → 已批准/需返工 → 外部分发`

输入无特性或字段不合法时不得创建生产任务；审核不通过时保留 run 产物并进入“需返工”。[S-001；返工处置为 inferred]
